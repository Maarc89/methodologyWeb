# PIM-PAM

**DESCRIPCIÓN**  
Es una aplicación web que permite gestionar y realizar evaluaciones en línea. Su objetivo es poder centralizar, organizar y agilizar todo el proceso enfocado en estas.

---

## 🚀 Características Principales

- ✅ Creación y importación de evaluaciones personalizadas 
- 👥 Gestión de usuarios con diferentes roles
- 📊 Panel de estadísticas con reportes de desempeño
- 🔐 Autenticación segura con control de acceso

## 🛠️ Tecnologías Utilizadas

### Backend
- `Django + Django REST Framework`
- `Gunicorn`
- `PostgreSQL`

### Frontend
- `React + Vite`
- `TailwindCSS`

### Otros
- `Docker`
- `Nginx`
